ระบบแจ้งนักเรียนไม่มีสิทธิ์สอบปลายภาค

โรงเรียนวีรวัฒน์โยธิน สำนักงานเขตพื้นที่การศึกษามัธยมศึกษาสุรินทร์

ภาคเรียนที่ 1/2569

ขอความร่วมมือคณะครูผู้สอนทุกท่าน โปรดดำเนินการบันทึกข้อมูลนักเรียนที่ไม่มีสิทธิ์สอบปลายภาค หรือมีแนวโน้มที่จะได้รับผลการเรียน 0, ร, มผ ประจำภาคเรียนที่ 1 ปีการศึกษา 2569 ตามกำหนดการที่สำคัญด้านล่างนี้

ครูผู้สอนบันทึกข้อมูลภายใน

เข้าสู่ระบบเพื่อบันทึกรายชื่อนักเรียน มส., 0, ร, มผ

3 กันยายน 2569

ประกาศรายชื่ออย่างเป็นทางการ

แจ้งให้นักเรียนและผู้ปกครองทราบรายบุคคล

7 กันยายน 2569

เข้าสู่ระบบบันทึกข้อมูล (AppSheet)

คลิกปุ่มด้านล่างเพื่อเข้าสู่ระบบบันทึกรายชื่อนักเรียนไม่มีสิทธิ์สอบปลายภาค 1/2569

คำแนะนำ: เพื่อความสะดวกและมองเห็นตารางข้อมูลชัดเจน แนะนำให้เข้าใช้งานผ่านคอมพิวเตอร์ (PC / Laptop)
คลิกที่นี่เพื่อบันทึกข้อมูลนักเรียน
คู่มือการใช้งาน

ขั้นตอนการบันทึกนักเรียนไม่มีสิทธิ์สอบ

คู่มือแนะนำขั้นตอนการใช้งานระบบบันทึกนักเรียน มส. และแนวโน้ม 0, ร, มผ สำหรับครูผู้สอน

แนะนำให้เข้าใช้งานผ่านจอคอมพิวเตอร์ (PC / Laptop) เพื่อความสะดวกในการกรอกและตรวจสอบข้อมูล
1

เพิ่มรายวิชาของท่าน

ในหน้ารายวิชา กดปุ่ม + add เพื่อเพิ่มรายวิชาที่สอน

พื้นที่สำหรับใส่ภาพหน้าจอขั้นตอนที่ 1 (แนวนอน)

แสดงหน้าจอการกด +add ในหน้ารายวิชา

2

เข้ารายวิชาของท่าน

เมื่อบันทึกการเพิ่มรายวิชาเรียบร้อยแล้ว ให้คลิก/กดเข้ารายวิชาของท่านเพื่อดำเนินการต่อ

พื้นที่สำหรับใส่ภาพหน้าจอขั้นตอนที่ 2 (แนวนอน)

แสดงรายการวิชาที่บันทึกแล้วและการคลิกเข้ารายวิชา

3

บันทึกข้อมูลนักเรียน มส. (ไม่มีสิทธิ์สอบ)

เลื่อนลงมาด้านล่าง จะพบปุ่ม Add เพื่อเพิ่มข้อมูลนักเรียน มส. บันทึกรายละเอียดให้ครบถ้วนแล้วกด Save

พื้นที่สำหรับใส่ภาพหน้าจอขั้นตอนที่ 3 (แนวนอน)

แสดงฟอร์มการบันทึกนักเรียน มส. และปุ่ม Save

4

บันทึกข้อมูลแนวโน้ม 0, ร, มผ

ถัดจากการบันทึก มส. จะพบส่วนบันทึกแนวโน้มผลการเรียน 0, ร และ มผ ให้กดปุ่ม Add เพื่อกรอกข้อมูลนักเรียน แล้วกด Save

พื้นที่สำหรับใส่ภาพหน้าจอขั้นตอนที่ 4 (แนวนอน)

แสดงส่วนการเพิ่มนักเรียนแนวโน้มติด 0, ร, มผ

5

ตรวจสอบและแก้ไขข้อมูล

ตรวจสอบข้อมูลให้ถูกต้อง หากต้องการแก้ไข ให้กดที่ชื่อนักเรียน เลือก Edit แก้ไขข้อมูลแล้วกด Save

พื้นที่สำหรับใส่ภาพหน้าจอขั้นตอนที่ 5 (แนวนอน)

แสดงการกดเลือกรายชื่อนักเรียน การ Edit และ Save

อ่านขั้นตอนเข้าใจแล้ว สามารถเข้าสู่ระบบเพื่อเริ่มบันทึกข้อมูลได้ทันที
